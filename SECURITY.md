# Security policy

Nabd runs only on your own computer: the server listens on `127.0.0.1` (not reachable from other devices), serves only the files in `web/`, and only downloads public price data.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Email **[ahmedosama181@outlook.com](mailto:ahmedosama181@outlook.com)** with:

- what the problem is and how to reproduce it,
- what an attacker could do with it,
- your operating system and Nabd version.

You will get a reply as soon as possible. Once fixed, the fix is released and you are credited if you wish.

## Supported versions

Only the latest version on the `main` branch is supported.
